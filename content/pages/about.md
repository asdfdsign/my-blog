마크다운으로 글을 쓰고, 빌드하면 정적 HTML이 나오는 개인 블로그입니다.

## 만든 방식

프레임워크를 쓰지 않았습니다. 빌드 스크립트도 Node 표준 라이브러리만 사용하고, 마크다운 파서는 블로그에 필요한 문법만 직접 구현했습니다. 브라우저로 내려가는 코드에는 외부 라이브러리도, 웹폰트 요청도 없습니다.

결과물은 그냥 HTML·CSS·JS 파일 묶음이라 아무 정적 호스팅에나 올라갑니다.

## 글 쓰는 법

`content/posts/` 에 마크다운 파일을 하나 만들고 빌드하면 끝입니다.

```bash
node src/build.mjs
```

파일명이 그대로 주소가 됩니다.
