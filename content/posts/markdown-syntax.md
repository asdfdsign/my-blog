이 글은 파서가 지원하는 문법을 전부 한 번씩 쓰는 회귀 확인용 페이지입니다. 파서를 고친 뒤 이 글이 멀쩡하면 대체로 안전합니다.

## 인라인

**굵게**, *기울임*, `인라인 코드`, 그리고 [외부 링크](https://example.com "제목 속성"). 인라인 코드 안의 별표는 `**굵어지지 않아야**` 합니다.

HTML 문자도 그대로 보여야 합니다: 5 < 10 이고 a & b 이며 "따옴표" 도 마찬가지입니다.

두 칸 이상 띄고 줄바꿈하면  
이렇게 줄이 나뉩니다.

## 목록

- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목
  - 또 하나의 중첩
    - 세 단계까지
- 세 번째 항목

순서 있는 목록:

1. 준비하기
2. 실행하기
3. 확인하기

## 인용문

> 인용문 안에서도 **굵게**와 `코드`가 동작합니다.
> 여러 줄을 이어 쓸 수 있습니다.

## 코드 블록

코드 블록 안에서는 어떤 인라인 변환도 일어나지 않습니다.

```js
// 이 안의 **별표**와 <태그>는 그대로 보여야 한다
const posts = files.map((file) => ({
  slug: path.basename(file, '.md'),
  html: renderMarkdown(read(file)),
}));
```

언어 표시가 없는 블록, 그리고 좁은 화면에서 가로 스크롤이 생기는지 볼 긴 줄:

```
이것은 일부러 아주 길게 늘여 쓴 한 줄입니다. 모바일 화면에서 이 줄 때문에 페이지 전체가 좌우로 밀리면 안 되고, 반드시 이 코드 블록 안에서만 스크롤되어야 합니다.
```
